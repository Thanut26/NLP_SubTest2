# 📈 Stock Investment RAG Chatbot

Web Application ระบบ RAG (Retrieval-Augmented Generation) สำหรับให้ความรู้และตอบคำถามพื้นฐานเกี่ยวกับการลงทุนในหุ้นและตลาดหลักทรัพย์

## 🎯 หัวข้อที่เลือก
- ผู้ช่วยให้ความรู้เรื่องหุ้นและการลงทุน (Stock Investment Knowledge Assistant)

## 🛠️ เทคโนโลยีที่ใช้
- **Streamlit**: สำหรับสร้าง Web Interface และออกแบบ UI/UX สไตล์มินิมอล (Light Theme)
- **Sentence-Transformers** (`all-MiniLM-L6-v2`): สำหรับแปลงข้อความเป็น Vector Embedding
- **FAISS**: สำหรับทำ Vector Search ค้นหาข้อมูลที่ใกล้เคียงที่สุด
- **Groq API**: สำหรับประมวลผลและสร้างคำตอบ (LLM) อย่างรวดเร็วและแม่นยำ

## 💡 วิธีการใช้งาน
1. พิมพ์คำถามเกี่ยวกับหุ้นหรือตลาดหลักทรัพย์ลงในช่องแชทหลัก
2. ระบบจะทำการดึงข้อมูล (Retrieval) จากเอกสารความรู้ในโฟลเดอร์ `data/` มาวิเคราะห์และตอบกลับเป็นภาษาธรรมชาติ พร้อมแนบแหล่งอ้างอิง (Citation) ทุกครั้ง
3. หากคำถามไม่มีข้อมูลสนับสนุนอยู่ในระบบ แชตบอตจะป้องกันการเดาข้อมูลเท็จ (Hallucination) และตอบว่า "ไม่พบข้อมูล" ตามหลักการของระบบ RAG ที่ดี
4. ผู้ใช้สามารถเรียกดูประวัติคำถามล่าสุด, ดูรายชื่อไฟล์ฐานข้อมูล, และสั่งรีโหลดข้อมูลใหม่ได้จากแถบเมนู (Sidebar) ด้านข้าง
